# Application of Machine Learning Algorithms for Carpal Tunnel Syndrome

## One-line thesis
On the same 315-patient Sakarya University ENMG cohort reformulated for binary CTS classification (80/20 split, n=64 test), SVM reaches 96% accuracy and 0.99 AUC (31/32 TN, 31/32 TP), outperforming Logistic Regression (93%), Naive Bayes (92%), and KNN (92%).
