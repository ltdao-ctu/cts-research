# Carpal tunnel syndrome prediction with machine learning algorithms using anthropometric and strength-based measurement

## One-line thesis
Using 13 non-invasive hand anthropometric and grip/pinch strength features on N=112 subjects (56 bilateral CTS + 56 healthy controls), Random Forests (mtry=4) achieves 89.474% test accuracy, F1=0.905, Kappa=0.789 (100% sensitivity, 78.9% specificity), driven by Wrist Circumference, Hand Width, Hand Grip Strength, and Tip/Key Pinch.
