# Automatic Electrodiagnosis of Carpal Tunnel Syndrome Using Machine Learning

## One-line thesis
Extracting 23 novel physiological/geometric NCS waveform features (expanded area, half-max duration, subarea ratios, onset/offset tangent slopes capturing axonal repolarization) alongside 11 standard features (302 features/hand across 8 nerves) with SBS+SFS and SVM achieves 96.92% (2-class vs NCS), 89.06% (2-class vs clinical, where novel features alone beat common features 87.48% vs 86.91%), 94.15% (3-class), and 91.17% (4-class) accuracy on 65 hands.
